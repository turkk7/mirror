# firmware — طبقة اللمس الافتراضية (ESP32-S3 + 2× VL53L1X)

برنامج المتحكّم الذي يقرأ المسافتين الخام من حسّاسَي ToF ويرسلهما عبر Web Serial.
المنطق الكامل (المعايرة، كشف اللمسة، حقن النقرة) في الواجهة: `frontend/js/touch-serial.js`.
التصميم الكامل: `docs/tof-touch-overlay.md`.

## التوصيل

| ESP32-S3 | الحسّاسان VL53L1X |
|---|---|
| GPIO8 (SDA) | SDA لكليهما (ناقل مشترك) |
| GPIO9 (SCL) | SCL لكليهما (ناقل مشترك) |
| GPIO4 | XSHUT للحسّاس العمودي (V) |
| GPIO5 | XSHUT للحسّاس الأفقي (H) |
| 3V3 / GND | VIN / GND لكليهما |

الأطراف معرّفة في أعلى `src/main.cpp` — عدّلها إن لزم.

**مقاومات السحب:** لا حاجة لمقاومات خارجية — ألواح VL53L1X الجاهزة (breakout) فيها سحب
I2C مدمج (~10kΩ)، والاثنان على التوازي (~5kΩ) سليم. أضف سحباً خارجياً فقط لو كانت القطعة
شريحة عارية بلا لوح، أو لو ظهر سلوك باص متقطّع/`S,err` عند التوصيل المباشر.

## البناء والرفع

```bash
# تثبيت PlatformIO مرة واحدة:  pip install platformio   (أو إضافة VS Code)
cd firmware
pio run                       # بناء
pio run -t upload             # رفع إلى اللوحة
pio device monitor -b 115200  # مراقبة الخرج الخام
```

عند الإقلاع يجب أن ترى `S,ready` ثم أسطر `R,dv,dh,vv,vh` متتالية.
`S,err,V` أو `S,err,H` = فشل إقلاع ذلك الحسّاس (تحقّق من XSHUT/الأسلاك/السحب).

## اختبار الطاولة (قبل أي تركيب في الإطار)

هذه هي الخطوة الحاسمة — تثبت الفكرة بأرخص تكلفة:

1. وصّل الحسّاسين على بريدبورد وافلش البرنامج.
2. راقب السيريال ولوّح بإصبعك على بُعد ١–٢ مم موازياً لعدسة الحسّاس (grazing).
3. تأكّد أن `dv`/`dh` **تنخفض بوضوح مع الإصبع** و`vv`/`vh = 1`، وترجع لقيمة ثابتة كبيرة بلا إصبع.
   - إن بقي القياس ثابتاً قريباً جداً دائماً → الحسّاس يرى الزجاج/السطح، ارفعه قليلاً.
4. إن نجح هذا → انتقل للتركيب والمعايرة (قسم ٩ في المستند).

## المعايرة من المتصفّح

افتح الكيوسك بـ `http://localhost:8000/?cal=1` → يظهر HUD أخضر بالقيم الخام.
ثم من console المتصفّح (عبر operator panel أو جهاز مطوّر):

```js
qamraTouch.raw()          // القيم الخام الحالية (d, v) + الموضع المحسوب ny
// معايرة سريعة بنقطتين (حسّاس عمودي واحد):
qamraTouch.markTop()      // ضع اليد أعلى منطقة الأزرار ثم نفّذه
qamraTouch.markBottom()   // ثم أسفلها
qamraTouch.tune({ minMm: 100, maxMm: 900 }) // ضبط بوابة المدى عند الحاجة
qamraTouch.getCal()       // عرض المعايرة الحالية

// معايرة كاملة بخمس نقاط (روتين تفاعلي على الشاشة):
qamraTouch.calibrate()
```

المعايرة السريعة (`markTop`/`markBottom`/`tune`) تُحفظ في `localStorage` (تبقى بعد إعادة
التحميل على هذا المتصفّح). أما `calibrate()` فيشغّل الروتين التفاعلي بخمس نقاط ويرسل
النقاط للخادم (`POST /api/touch/cal`) فتسري على الكيوسك وتبقى بعد إعادة التشغيل.
```
