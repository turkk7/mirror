# مرآة الفوتوبوث — Smart Mirror Photobooth

تطبيق فوتوبوث لمرآة ذكية. البوث الحيّ يعمل حاليًا على **ماك بوك برو 2015 بنظام Ubuntu 26.04 LTS** (ويعمل أيضاً على macOS للتطوير).

- **الواجهة (Frontend):** HTML/CSS/JS بملء الشاشة، تعمل في متصفح Chromium بوضع Kiosk (على Wayland) على جهاز البوث.
- **الخلفية (Backend):** Python + Flask، وستتحكم لاحقاً بالكاميرا (gphoto2) والطباعة (CUPS).

## البنية

```
mirror/
├── backend/            # خادم Flask + منطق الكاميرا والطباعة
│   ├── app.py          # نقطة الدخول + المسارات
│   ├── config.py       # الإعدادات
│   └── requirements.txt
├── frontend/           # الواجهة
│   ├── index.html
│   ├── css/styles.css
│   └── js/main.js
├── run.sh              # سكربت التشغيل (ينشئ venv ويشغّل الخادم)
└── README.md
```

## التشغيل

```bash
./run.sh
```

ثم افتح المتصفح على: http://localhost:8000

## نشر البوث (الإنتاج)

البوث يعمل على ماك بوك برو 2015 بنظام Ubuntu، ويبدأ كل شيء تلقائياً عند الإقلاع:

- المشروع على البوث في `/home/turkk/mirror` (يُنقل بـ `rsync` من ماك التطوير).
- **الخادم**: خدمة systemd باسم `qamra-backend.service` (تعمل تلقائياً وتعيد نفسها عند التعطّل).
- **الواجهة**: دخول تلقائي لـ GNOME ثم `~/.config/autostart/qamra-kiosk.desktop` يشغّل `~/mirror/kiosk.sh` الذي يفتح Chromium بملء الشاشة على `http://localhost:8000`.
- **الشاشة**: تلفاز HDMI بوضع **عمودي**؛ شاشة الماك الداخلية معطّلة (مكسورة)؛ النوم وإطفاء الشاشة معطّلان؛ إغلاق الغطاء لا يُطفئ الجهاز.
- **خلفية سوداء دامسة** مع شعار عالي الدقة — مناسب للمرآة.

## الوصول عن بُعد

- **إدارة النظام**: SSH بمفتاح — `ssh qamra` من ماك التطوير.
- **لوحة المشغّل من أي مكان**: عبر **Tailscale** (اسم الجهاز `qamra`) — `http://<عنوان-Tailscale>:8000/admin`، دون تعريض البوث للإنترنت العام.
- **ملاحظة**: البطارية لم تعد تحمل شحناً — البوث ينطفئ فور فصل الكهرباء، فأمّن مصدر كهرباء ثابتاً.

## لوحة المشغّل

- الرابط: `‎/admin` — افتحه على جوالك عبر عنوان المرآة في الشبكة المحلية.
- الرمز الافتراضي `1234` — **غيّره من داخل اللوحة** (قسم «الأمان» ← تغيير الرمز). هذا هو الطريق الصحيح لتغيير رمزٍ قائم.
- `MIRROR_ADMIN_PIN` يهيّئ الرمز **أول تشغيل فقط**؛ بعد حفظ الإعدادات يُستعاد الرمز المحفوظ (`data/settings.json`) فوق قيمة البيئة، فلن يغيّره تعديل المتغيّر لاحقاً.

## مبدأ تجربة المستخدم

- **الضيف** يرى تجربة بسيطة فقط (ابدأ · التقاط · اطبع/نسخة رقمية · شكراً).
- **المشغّل** (صاحب الجهاز) يرى المعلومات التشغيلية في لوحة ‎/admin منفصلة على جواله.
- لا تُعرض أي أرقام باقة أو حالة تقنية على شاشة الضيف.
- عودة تلقائية لشاشة الانتظار عند خمول الضيف (تجهيز للتالي).
